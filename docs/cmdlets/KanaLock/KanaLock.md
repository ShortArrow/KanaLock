# KanaLock Module

## Description

Read and clear the kana lock (VK_KANA) toggle on Windows, which turns typed letters into half-width kana wherever the IME is off and cannot be cleared by hand on a 101-key keyboard.

## KanaLock

### [Disable-KanaLock](Disable-KanaLock.md)

Turns kana lock off.

### [Enable-KanaLock](Enable-KanaLock.md)

Turns kana lock on.

### [Get-KanaLock](Get-KanaLock.md)

Returns whether kana lock is on.
